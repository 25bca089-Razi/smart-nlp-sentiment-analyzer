🔍 Smart NLP Text Analyzer
Intelligent Text Processing and Sentiment Analysis Dashboard
📌 Project Overview

Smart NLP Text Analyzer is an interactive Natural Language Processing (NLP) application developed using Python and Gradio. It analyzes user-provided text and performs various NLP operations, including text cleaning, tokenization, stopword removal, stemming, lemmatization, and sentiment analysis.

The application provides an easy-to-use dashboard where users can explore text preprocessing results and understand the emotional tone of written content.

✨ Features
Text Cleaning: Removes URLs, punctuation, special characters, and extra spaces.
Tokenization: Breaks text into individual words.
Stopword Removal: Removes commonly used English words.
Stemming: Reduces words to their root forms using Porter Stemmer.
Lemmatization: Converts words into their meaningful base forms using WordNet.
Sentiment Analysis: Classifies text as Positive, Negative, or Neutral.
Polarity Analysis: Measures the emotional orientation of text.
Subjectivity Analysis: Determines whether text is objective or subjective.
Word Frequency Analysis: Identifies the ten most frequently occurring words.
Text Statistics: Displays characters, words, tokens, unique words, and sentences.
Interactive Dashboard: Provides a user-friendly interface using Gradio.
